# Deck logo sources

- `ai-builders-mexico.svg`, `openai.svg`, `spacex-ai.svg`, and `google.png`: existing AI Builders México website assets in `website-v2/public/`.
- `bbva.svg` and `walmart.svg`: existing corporate workshop logo assets in `website-v2/public/logos/enterprise/`.
- `cursor.svg` and `vercel.svg`: existing partner assets in this repository's `public/brand/partners/` directory.
- `nvidia.svg`: NVIDIA's horizontal logo from `https://www.nvidia.com/content/dam/en-zz/Solutions/about-nvidia/logo-and-brand/nvidia-logo-horz.svg`.
- `pwc.svg`: PwC's logo from `https://www.pwc.com/gx/en/brand/pwc-logo.svg`.

The deck displays the marks as image files without redrawing them.
