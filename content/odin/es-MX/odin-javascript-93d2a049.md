# Cómo trabajar este curso de JavaScript

JavaScript es el lenguaje que ya usaste para responder a clics y transformar datos. Ahora vamos a profundizar: herencia por prototipos, organización de objetos, módulos, empaquetado, código asíncrono y pruebas. El objetivo es poder explicar qué ocurre cuando una aplicación cambia de estado, no solamente conseguir que una pantalla se vea bien.

Antes de construir interfaces con React y Next.js, practicarás estos fundamentos con JavaScript sin framework. React tiene reglas propias para actualizar una pantalla, y Next.js agrega decisiones sobre servidor y navegador. Esas reglas resultan mucho más comprensibles cuando ya sabes separar datos de presentación, importar módulos y esperar una promesa.

## Cómo avanzar

Sigue el orden del curso. Las lecciones presentan conceptos y remiten a lecturas; los proyectos te obligan a elegir una estructura y completar una aplicación sin una solución paso a paso. Una lectura marcada como tarea forma parte del trabajo: abrir el enlace no equivale a haberla completado. Escribe ejemplos, cambia sus entradas y explica el resultado.

Vas a olvidar sintaxis de cursos anteriores y también de éste. Consultar documentación es parte normal del trabajo. No necesitas memorizar todos los métodos; necesitas reconocer el tipo de problema, saber dónde buscar y verificar que una solución corresponde a tu caso. Lee la reflexión de Odin sobre [memorización y aprendizaje](https://dev.to/theodinproject/memorization-and-learning-to-code-1b6h).

Si una lección se vuelve difícil, identifica la primera expresión que no comprendes. Reproduce un ejemplo pequeño, observa variables con el depurador y anota qué esperabas y qué ocurrió. Descansar y regresar al problema suele ser más útil que copiar una implementación completa.

## Tu cuaderno de trabajo

1. Conserva un repositorio para cada proyecto y escribe sus instrucciones de ejecución.
2. Registra las decisiones que tomes: por qué usaste una fábrica, qué devuelve una función y quién modifica el DOM.
3. Al terminar una lección, responde sus preguntas sin mirar; vuelve únicamente a los puntos que no puedas explicar.
4. Antes de pasar a React, abre un proyecto anterior y sigue el recorrido de un clic desde el evento hasta los datos y la pantalla.

## Comprobación

- Puedes describir la diferencia entre aprender el lenguaje y aprender las convenciones de un framework.
- Tienes una estrategia concreta para investigar un error sin depender de una solución completa.
