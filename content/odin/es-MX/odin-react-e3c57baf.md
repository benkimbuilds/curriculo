# Cómo trabajar este curso

En este curso aprenderás React desde componentes y JSX hasta estado, efectos, pruebas, rutas y administración de datos. Los proyectos intermedios —un generador de currículum, un juego de memoria y una tienda con carrito— sirven para practicar decisiones reales y construir evidencia para tu portafolio.

Antes de empezar, completa el [curso de JavaScript de Odin](https://www.theodinproject.com/paths/full-stack-javascript/courses/javascript) y sus equivalentes en Ruta. React sigue siendo JavaScript: necesitarás leer funciones, módulos, objetos, arreglos, promesas, callbacks y desestructuración. Si `map`, una función flecha o una actualización inmutable todavía parecen magia, vuelve al ejercicio correspondiente. Aprender dos capas desconocidas al mismo tiempo hace más difícil encontrar la causa de un error.

## El recorrido

Cada lección incluye explicación, ejemplos y actividades. Escribe y modifica los ejemplos; los ejercicios interactivos de la documentación también forman parte del trabajo. Haz una predicción antes de ejecutarlos y conserva una nota cuando el resultado no coincida. No necesitas memorizar todas las APIs, pero sí explicar por qué una interacción cambia la interfaz.

Al principio quizá pienses que sería más fácil hacerlo con JavaScript sin React. Esa comparación es útil: considera el [proyecto de lista de tareas](https://www.theodinproject.com/lessons/node-path-javascript-todo-list) que ya construiste y todo el código que necesitabas para mantener DOM y datos sincronizados. React permite describir la interfaz a partir del estado y componer piezas reutilizables. La ventaja se vuelve más clara a medida que aparecen filtros, edición y varias vistas del mismo dato.

En Ruta mantenemos los fundamentos de React y usamos Next.js para rutas y despliegue. Encontrarás esos reemplazos señalados; el original inglés se conserva para auditoría. El calendario de doce semanas organiza el trabajo, pero no convierte todos estos proyectos en tareas de una hora: registra avances y continúa las prácticas que requieran más tiempo.

## Actividad

1. Revisa tu proyecto de lista de tareas y enumera qué cambia cuando agregas, editas o eliminas una tarea.
2. Dibuja los componentes que podrían representar ese comportamiento.
3. Crea un registro de aprendizaje para anotar errores, decisiones y preguntas durante este curso.
