# Proyecto: página de presentación

Construye una página completa a partir del [diseño de referencia de Odin](https://cdn.statically.io/gh/TheOdinProject/curriculum/81a5d553f4073e593d23a6ab00d50eef8620796d/foundations/html_css/project/imgs/01.png). La práctica consiste en transformar una imagen en estructura HTML y distribución CSS. No se exige coincidencia píxel por píxel, pero sí conservar las relaciones entre secciones y componentes.

Prepara un repositorio antes de comenzar. Si necesitas ayuda, revisa el [proyecto Recetario](https://www.theodinproject.com/lessons/foundations-recipes). Crea commits pequeños durante el trabajo siguiendo la [lección de mensajes](https://www.theodinproject.com/paths/foundations/courses/foundations/lessons/commit-messages).

## Referencia visual

El diseño tiene cuatro secciones principales y un pie: presentación con navegación y hero, información con tarjetas, una cita y una llamada a la acción. Éstos son sus valores de referencia, que puedes adaptar si personalizas el contenido:

- Fuente Roboto, que tendrás que incorporar si no está disponible; conserva una alternativa genérica.
- Fondo oscuro de encabezado, hero y pie: `#1F2937`.
- Logotipo textual: 24px y `#F9FAF8`.
- Encabezado principal del hero: 48px, peso 900 y `#F9FAF8`.
- Texto secundario del hero y enlaces de navegación: 18px y `#E5E7EB`.
- Botones y fondo de llamada a la acción: `#3882F6`.
- Encabezado de información: 36px, peso 900 y `#1F2937`.
- Cita: fondo `#E5E7EB`, texto de 36px, peso 300, cursiva y color `#1F2937`.

Puedes inventar una organización o un producto y reemplazar los textos provisionales e imágenes. Conserva la estructura que hace practicar los mismos problemas de distribución. Busca recursos con permiso de uso en [Pexels](https://www.pexels.com/), [Pixabay](https://pixabay.com/) o [Unsplash](https://unsplash.com/) y revisa cada licencia; acredita autores en el README cuando corresponda.

## Construcción por secciones

1. Examina el diseño y dibuja las cajas principales. Identifica qué elementos comparten fila y cuáles se apilan.
2. Comienza por una sección, preferentemente arriba. Escribe primero su HTML completo y después sus estilos. Una sola hoja CSS es suficiente.
3. Construye navegación, título, texto, botón e imagen del hero. Decide qué contenedor agrupa cada fila y qué separación pertenece a padding o gap.
4. Añade información con sus tarjetas, la cita con atribución, la llamada a la acción y el pie. Vuelve a los ejercicios flex si necesitas recordar una distribución.
5. Compara el conjunto con la imagen. Ajusta tamaños relativos, alineación y espacios; no pierdas tiempo midiendo cada píxel.

Puedes investigar detalles pequeños aún no explicados, como esquinas redondeadas. Consultar documentación y lecciones anteriores es parte esperada del trabajo. No necesitas hacerlo todo de memoria.

## Entrega y comprobación

El requisito original se centra en escritorio: no exige todavía adaptar a móviles, zoom o todos los tamaños. Esa capacidad se desarrollará más adelante. Comprueba al menos que el diseño funciona en una ventana normal de computadora, que ningún texto toca accidentalmente los bordes y que los enlaces con destino real funcionan.

Publica el repositorio y despliega con GitHub Pages siguiendo la [sección de publicación del recetario](https://www.theodinproject.com/lessons/foundations-recipes#viewing-your-project-on-the-web). Abre la URL publicada y revisa las cuatro secciones, el pie, las imágenes y la hoja de estilos. Guarda en el README la URL, créditos y una explicación de dos decisiones de distribución. La aceptación consiste en una página completa construida por ti, reconocible respecto a la referencia y con historial de trabajo comprobable.
## Profundiza con el ejemplo

Antes de entregar, confirma que cada imagen tiene permiso de uso y que el README atribuye su origen. La personalización del contenido debe conservar la práctica de composición, no eliminar secciones que te resultaron difíciles.
