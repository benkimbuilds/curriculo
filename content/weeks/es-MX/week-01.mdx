# Empieza como desarrollador o desarrolladora

Prepara un espacio de trabajo confiable, pierde el miedo a la terminal, publica con Git y crea desde cero un perfil personal con HTML semántico. Esta edición está escrita para quien empieza desde cero y puede trabajar en Windows o macOS. Completa las lecciones en orden: cada una incluye explicación, ejemplo, práctica y evidencia antes del proyecto semanal.

## Proyecto semanal

Crea y publica un perfil de una página que explique tu meta, muestre una lista pequeña de proyectos y lleve claramente a tu perfil de GitHub.

### Entregables

- Un repositorio público en GitHub con al menos cinco commits con propósito.
- Una página HTTPS publicada con header, navegación, main, secciones y footer semánticos.
- Un README con instalación, evidencia de validación y una reflexión de aprendizaje.

Antes de entregar, abre el proyecto desde una sesión limpia, recorre el flujo principal y compara cada criterio de la rúbrica con evidencia concreta. No incluyas contraseñas, tokens, ubicaciones precisas ni datos personales reales.
