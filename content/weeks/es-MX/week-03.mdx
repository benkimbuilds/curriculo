# Programa con JavaScript

Aprende variables, decisiones, ciclos, funciones, arreglos, objetos, depuración y pruebas al convertir problemas cotidianos en pasos pequeños y verificables. Esta edición está escrita para quien empieza desde cero y puede trabajar en Windows o macOS. Completa las lecciones en orden: cada una incluye explicación, ejemplo, práctica y evidencia antes del proyecto semanal.

## Valores y flujo de control

### Explicación

Explora strings, números, booleanos, null, undefined, comparaciones, condiciones y ciclos. Traza cada cambio en papel antes de preguntarle a la computadora. La meta no es memorizar sintaxis aislada, sino poder explicar qué información entra, qué decisión toma cada paso y qué evidencia muestra que funciona. Antes de copiar algo, predice el resultado. Si el resultado cambia, reduce el caso hasta entender una sola causa. Este hábito evita que una persona principiante dependa de ensayo y error y deja una ruta clara para pedir ayuda.

### Ejemplo

Lee el ejemplo de arriba hacia abajo y señala qué parte representa entrada, transformación y resultado. Escríbelo a mano en un archivo de práctica: teclear obliga a notar puntuación, nombres y estructura que se pierden al copiar y pegar.

```js
const amount = 250;
const isExpense = true;
const signedAmount = isExpense ? -amount : amount;
console.log(signedAmount);
```

Si te atoras, vuelve al ejemplo mínimo, lee el primer error completo y cambia una sola cosa. Pide ayuda compartiendo la predicción, el resultado real y lo que ya probaste, nunca una contraseña o token.

### Ejercicio guiado

1. Crea una carpeta o archivo desechable para esta lección y escribe una predicción concreta antes de ejecutar el ejemplo.
2. Teclea el ejemplo, ejecútalo o revísalo con la herramienta apropiada y compara el resultado con tu predicción. Conserva el mensaje exacto si falla.
3. Traza los valores antes de ejecutar; prueba cero, un decimal y un string para ver por qué importa normalizar entradas.
4. Haz un commit sólo si el cambio pertenece a tu proyecto; si era práctica desechable, resume en tus notas lo que aprendiste.

### Comprobación

- Elegir comparaciones estrictas y condiciones explícitas. Muéstralo con una ejecución, captura, prueba o explicación propia; repetir la frase no cuenta como evidencia.
- Trazar un ciclo y explicar cuándo termina. Muéstralo con una ejecución, captura, prueba o explicación propia; repetir la frase no cuenta como evidencia.

## Proyecto semanal

Crea una calculadora en el navegador que reciba ingresos y gastos, rechace valores inválidos, agrupe totales y explique el balance sin guardar datos sensibles.

### Entregables

- Funciones puras de cálculo con pruebas para casos normales, vacíos, decimales e inválidos.
- Un formulario usable con validación en contexto y formato de pesos mexicanos.
- Una bitácora sobre estructuras elegidas, un defecto encontrado y la prueba que demuestra la corrección.

Antes de entregar, abre el proyecto desde una sesión limpia, recorre el flujo principal y compara cada criterio de la rúbrica con evidencia concreta. No incluyas contraseñas, tokens, ubicaciones precisas ni datos personales reales.
