# Sustenta y evalúa un asistente de IA

Recupera fuentes aprobadas, adjunta citas, restringe herramientas, crea evaluaciones adversariales y mide calidad, latencia y costo en vez de confiar en una demo. Esta edición está escrita para quien empieza desde cero y puede trabajar en Windows o macOS. Completa las lecciones en orden: cada una incluye explicación, ejemplo, práctica y evidencia antes del proyecto semanal.

<!-- lesson:week-10-lesson-01 -->
## Recuperación con procedencia

### Explicación

Divide material aprobado por significado, guarda metadatos, recupera pocos fragmentos relevantes y exige que cada afirmación apunte a una fuente visible. La meta no es memorizar sintaxis aislada, sino poder explicar qué información entra, qué decisión toma cada paso y qué evidencia muestra que funciona. Antes de copiar algo, predice el resultado. Si el resultado cambia, reduce el caso hasta entender una sola causa. Este hábito evita que una persona principiante dependa de ensayo y error y deja una ruta clara para pedir ayuda.

### Ejemplo

Lee el ejemplo de arriba hacia abajo y señala qué parte representa entrada, transformación y resultado. Escríbelo a mano en un archivo de práctica: teclear obliga a notar puntuación, nombres y estructura que se pierden al copiar y pegar.

```json
{
  "chunk": "A commit records a checkpoint...",
  "sourceId": "git-notes-v1",
  "url": "https://example.org/git-notes"
}
```

Si te atoras, vuelve al ejemplo mínimo, lee el primer error completo y cambia una sola cosa. Pide ayuda compartiendo la predicción, el resultado real y lo que ya probaste, nunca una contraseña o token.

### Ejercicio guiado

1. Crea una carpeta o archivo desechable para esta lección y escribe una predicción concreta antes de ejecutar el ejemplo.
2. Teclea el ejemplo, ejecútalo o revísalo con la herramienta apropiada y compara el resultado con tu predicción. Conserva el mensaje exacto si falla.
3. Recupera dos fragmentos conservando la fuente y muestra qué hace el asistente cuando ninguno respalda la pregunta.
4. Haz un commit sólo si el cambio pertenece a tu proyecto; si era práctica desechable, resume en tus notas lo que aprendiste.

### Comprobación

- Conservar título y URL durante la recuperación. Muéstralo con una ejecución, captura, prueba o explicación propia; repetir la frase no cuenta como evidencia.
- Distinguir falta de evidencia de una respuesta negativa. Muéstralo con una ejecución, captura, prueba o explicación propia; repetir la frase no cuenta como evidencia.

## Proyecto semanal

Crea un asistente que responda sólo con notas aprobadas del curso. Debe citar, abstenerse sin evidencia y funcionar aun sin crédito de API.

### Entregables

- Índice con metadatos estables y citas navegables para cada respuesta respaldada.
- Evaluaciones versionadas con casos normales, ambiguos, sin evidencia, de inyección y acción no autorizada.
- Reporte comparativo de citas, abstención, latencia, costo estimado y fallos observados.

Antes de entregar, abre el proyecto desde una sesión limpia, recorre el flujo principal y compara cada criterio de la rúbrica con evidencia concreta. No incluyas contraseñas, tokens, ubicaciones precisas ni datos personales reales.
