# Crea experiencias web interactivas

Conecta JavaScript con el documento, administra eventos, guarda preferencias pequeñas y consume APIs públicas con estados honestos de carga, vacío y error. Esta edición está escrita para quien empieza desde cero y puede trabajar en Windows o macOS. Completa las lecciones en orden: cada una incluye explicación, ejemplo, práctica y evidencia antes del proyecto semanal.

## DOM y eventos

### Explicación

Selecciona elementos estables, escucha eventos intencionales, actualiza sólo la región afectada y delega eventos cuando varios controles comparten comportamiento. La meta no es memorizar sintaxis aislada, sino poder explicar qué información entra, qué decisión toma cada paso y qué evidencia muestra que funciona. Antes de copiar algo, predice el resultado. Si el resultado cambia, reduce el caso hasta entender una sola causa. Este hábito evita que una persona principiante dependa de ensayo y error y deja una ruta clara para pedir ayuda.

### Ejemplo

Lee el ejemplo de arriba hacia abajo y señala qué parte representa entrada, transformación y resultado. Escríbelo a mano en un archivo de práctica: teclear obliga a notar puntuación, nombres y estructura que se pierden al copiar y pegar.

```js
const list = document.querySelector("[data-list]");
list.addEventListener("click", (event) => {
  const button = event.target.closest("button");
  if (button) button.closest("li").remove();
});
```

## Proyecto semanal

Usa un conjunto público documentado para buscar o filtrar información útil sobre México. Guarda sólo preferencias no sensibles e indica fuente y fecha.

### Entregables

- Búsqueda o filtros responsivos con estados de carga, vacío, éxito y error recuperable.
- Integración con una API HTTPS pública, validación de respuesta y enlace visible a la fuente.
- Lista de pruebas manuales para teclado, red lenta, datos inesperados y desconexión.

Antes de entregar, abre el proyecto desde una sesión limpia, recorre el flujo principal y compara cada criterio de la rúbrica con evidencia concreta. No incluyas contraseñas, tokens, ubicaciones precisas ni datos personales reales.
