# Colabora con JavaScript mantenible

Organiza código en módulos, prueba el comportamiento, administra ramas, revisa pull requests e integra un tablero compartido sin esconder conflictos. Esta edición está escrita para quien empieza desde cero y puede trabajar en Windows o macOS. Completa las lecciones en orden: cada una incluye explicación, ejemplo, práctica y evidencia antes del proyecto semanal.

## Módulos y dependencias

### Explicación

Divide por responsabilidad, exporta la superficie mínima, inyecta dependencias variables y separa transformaciones de datos de la representación visual. La meta no es memorizar sintaxis aislada, sino poder explicar qué información entra, qué decisión toma cada paso y qué evidencia muestra que funciona. Antes de copiar algo, predice el resultado. Si el resultado cambia, reduce el caso hasta entender una sola causa. Este hábito evita que una persona principiante dependa de ensayo y error y deja una ruta clara para pedir ayuda.

### Ejemplo

Lee el ejemplo de arriba hacia abajo y señala qué parte representa entrada, transformación y resultado. Escríbelo a mano en un archivo de práctica: teclear obliga a notar puntuación, nombres y estructura que se pierden al copiar y pegar.

```text
app.js -> task-store.js
app.js -> task-view.js
task-view.js -> task-store.js
```

Si te atoras, vuelve al ejemplo mínimo, lee el primer error completo y cambia una sola cosa. Pide ayuda compartiendo la predicción, el resultado real y lo que ya probaste, nunca una contraseña o token.

### Ejercicio guiado

1. Crea una carpeta o archivo desechable para esta lección y escribe una predicción concreta antes de ejecutar el ejemplo.
2. Teclea el ejemplo, ejecútalo o revísalo con la herramienta apropiada y compara el resultado con tu predicción. Conserva el mensaje exacto si falla.
3. Elimina la dependencia de view hacia store pasando datos o callbacks y explica por qué ahora es más fácil probar.
4. Haz un commit sólo si el cambio pertenece a tu proyecto; si era práctica desechable, resume en tus notas lo que aprendiste.

### Comprobación

- Dibujar un mapa sin importaciones circulares. Muéstralo con una ejecución, captura, prueba o explicación propia; repetir la frase no cuenta como evidencia.
- Separar un script grande en módulos comprobables. Muéstralo con una ejecución, captura, prueba o explicación propia; repetir la frase no cuenta como evidencia.

## Proyecto semanal

En un equipo pequeño, crea un tablero con módulos independientes como tareas, temporizador y notas diarias. Acuerden interfaces antes de repartirse el trabajo.

### Entregables

- Repositorio compartido con issues, flujo protegido de main y al menos un pull request revisado por integrante.
- JavaScript modular con pruebas de la lógica principal y sin secretos ni datos personales.
- Reporte de integración con conflictos, cambios por revisión, comprobaciones finales y aportación individual.

Antes de entregar, abre el proyecto desde una sesión limpia, recorre el flujo principal y compara cada criterio de la rúbrica con evidencia concreta. No incluyas contraseñas, tokens, ubicaciones precisas ni datos personales reales.
