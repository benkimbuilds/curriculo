# Diseña páginas responsivas e incluyentes

Usa CSS con intención, adapta interfaces desde teléfonos hasta monitores del laboratorio y verifica que funcionen con teclado y tecnologías de asistencia. Esta edición está escrita para quien empieza desde cero y puede trabajar en Windows o macOS. Completa las lecciones en orden: cada una incluye explicación, ejemplo, práctica y evidencia antes del proyecto semanal.

## Fundamentos de CSS

### Explicación

Conecta hojas de estilo, inspecciona estilos calculados y razona sobre especificidad, herencia, unidades, color y modelo de caja en vez de cambiar números a ciegas. La meta no es memorizar sintaxis aislada, sino poder explicar qué información entra, qué decisión toma cada paso y qué evidencia muestra que funciona. Antes de copiar algo, predice el resultado. Si el resultado cambia, reduce el caso hasta entender una sola causa. Este hábito evita que una persona principiante dependa de ensayo y error y deja una ruta clara para pedir ayuda.

### Ejemplo

Lee el ejemplo de arriba hacia abajo y señala qué parte representa entrada, transformación y resultado. Escríbelo a mano en un archivo de práctica: teclear obliga a notar puntuación, nombres y estructura que se pierden al copiar y pegar.

```css
.notice { color: navy; }
main .notice { color: teal; }
.notice { color: purple; }
```

Si te atoras, vuelve al ejemplo mínimo, lee el primer error completo y cambia una sola cosa. Pide ayuda compartiendo la predicción, el resultado real y lo que ya probaste, nunca una contraseña o token.

### Ejercicio guiado

1. Crea una carpeta o archivo desechable para esta lección y escribe una predicción concreta antes de ejecutar el ejemplo.
2. Teclea el ejemplo, ejecútalo o revísalo con la herramienta apropiada y compara el resultado con tu predicción. Conserva el mensaje exacto si falla.
3. Predice el color final, verifícalo en estilos calculados y haz que gane la primera regla sin usar important.
4. Haz un commit sólo si el cambio pertenece a tu proyecto; si era práctica desechable, resume en tus notas lo que aprendiste.

### Comprobación

- Predecir qué declaración gana en la cascada. Muéstralo con una ejecución, captura, prueba o explicación propia; repetir la frase no cuenta como evidencia.
- Diagnosticar espacios con las herramientas del navegador. Muéstralo con una ejecución, captura, prueba o explicación propia; repetir la frase no cuenta como evidencia.

## Proyecto semanal

Diseña una página responsiva para un servicio local ficticio, como biblioteca, centro de reciclaje o taller comunitario. La acción principal debe funcionar sin mouse.

### Entregables

- Layouts responsivos a 360, 768 y 1280 píxeles CSS sin desbordamiento horizontal.
- Un recorrido completo con teclado, foco visible y etiquetas de formulario asociadas.
- Una nota breve que explique jerarquía, color, tipografía y revisiones de accesibilidad.

Antes de entregar, abre el proyecto desde una sesión limpia, recorre el flujo principal y compara cada criterio de la rúbrica con evidencia concreta. No incluyas contraseñas, tokens, ubicaciones precisas ni datos personales reales.
