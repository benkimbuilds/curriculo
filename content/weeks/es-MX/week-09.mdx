# Agrega una función de IA acotada

Define una tarea pequeña asistida por un modelo, protege datos privados, exige salida estructurada, controla costo y conserva utilidad si el modelo falla. Esta edición está escrita para quien empieza desde cero y puede trabajar en Windows o macOS. Completa las lecciones en orden: cada una incluye explicación, ejemplo, práctica y evidencia antes del proyecto semanal.

## Definición de producto con IA

### Explicación

Separa el problema del modelo. Define entrada, salida permitida, ejemplos de éxito, conductas inaceptables y un flujo sin costo antes de elegir proveedor. La meta no es memorizar sintaxis aislada, sino poder explicar qué información entra, qué decisión toma cada paso y qué evidencia muestra que funciona. Antes de copiar algo, predice el resultado. Si el resultado cambia, reduce el caso hasta entender una sola causa. Este hábito evita que una persona principiante dependa de ensayo y error y deja una ruta clara para pedir ayuda.

## Proyecto semanal

Agrega al gestor una función opcional que sugiera pasos pequeños desde una descripción no sensible. La persona aprueba cada tarea antes de guardarla.

### Entregables

- Contrato de tarea, esquema de salida y validación documentados antes de persistir.
- Límite de frecuencia, tiempo y costo, errores seguros y logs sin descripciones ni credenciales.
- Revisión editable y alternativa sin costo basada en plantilla.

Antes de entregar, abre el proyecto desde una sesión limpia, recorre el flujo principal y compara cada criterio de la rúbrica con evidencia concreta. No incluyas contraseñas, tokens, ubicaciones precisas ni datos personales reales.
